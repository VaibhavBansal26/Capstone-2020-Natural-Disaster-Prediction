Compare the current weather at a point with what the surrounding weather stations report, using the OpenWeather API. Unlike the other modules this one needs an API key and makes a live request.

How it works

  1. Fetch the current observation for the given coordinates.
  2. Fetch the stations in a box around the point and take the most common condition as the "prediction".
  3. Report whether prediction and observation agree, and the conditions seen nearby.
