When enabled, the server checks the USGS earthquake feed on a schedule. When a new, real earthquake at or above the threshold appears, it composes an alert (with hospitals and police stations found near the epicentre) and sends it to the contacts configured on the server by email and/or SMS. The first check after a fresh start only records the quakes already in the feed, so enabling it never sends a burst of old alerts. USGS data can lag by a few minutes, and the message says it is not an official warning.

How to turn it on

It is off by default. Add these to the .env file (or the environment) and restart the server:

NDP_WATCH_QUAKES=true
NDP_WATCH_MIN_MAGNITUDE=6.0
NDP_ALERTS_DRY_RUN=true   # try it first: records what would be sent, sends nothing
NDP_ALERT_TO_EMAIL=you@example.com
NDP_SMTP_USER=...  NDP_SMTP_PASSWORD=...

Set NDP_ALERTS_DRY_RUN=false only when you are ready for real messages.
