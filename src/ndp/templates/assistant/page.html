The assistant is not enabled on this server

It needs an Anthropic API key. Everything else in the app works without one.

  1. Create a key in the Anthropic Console.
  2. Make it available to the server, either in the shell or in a .env file in the project root: 
    ANTHROPIC_API_KEY=your-key-here
    (NDP_ANTHROPIC_API_KEY works too.)
  3. Restart the server: uv run ndp-serve.

Optional: NDP_ANTHROPIC_MODEL (default claude-opus-5-5; a smaller model such as claude-sonnet-5-5 costs less) and NDP_ASSISTANT_MAX_TOOL_ROUNDS (default 6).
