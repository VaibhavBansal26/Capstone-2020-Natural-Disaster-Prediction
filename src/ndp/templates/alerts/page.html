How the flow works

  1. The place name is geocoded with Nominatim (OpenStreetMap).
  2. Hospitals and police stations within the radius are fetched from the Overpass API and shown on a map with address and phone where tagged.
  3. A message prefilled with the nearest facilities can be sent by email (SMTP) and SMS (Twilio) when those are configured, after you confirm.
  4. The Live page can watch the USGS feed for new strong earthquakes (magnitude 6 or more by default) and send this same alert automatically. It is off by default; set NDP_WATCH_QUAKES=true, and try it with NDP_ALERTS_DRY_RUN=true first.
